### Elephants in the Room

1. **마감 기준으로는 LiveKit이 더 안전하다는 사실.** OME를 고른 이유에는 LL-HLS와 자체 호스팅을 직접 다뤄 보는 학습 가치도 들어 있을 수 있다. 정당한 이유지만, 그렇다면 D2 컷 규칙을 감정 없이 지킬 수 있어야 한다.
   - 대화 시작: "D2 18:00에 스파이크 기준 하나라도 실패하면, 아쉬워도 LiveKit으로 간다. 지금 이 약속을 할 수 있나?"
   - **해소 (2026-11-09)**: 약속함. 판정 시점은 D3 18:00으로 옮겼다.
2. **검증할 수 없는 환경을 README에 지원한다고 적을 위험.** 개발 기기가 macOS라 Windows 시스템 소리, Android 송출을 직접 확인하지 못할 수 있다.
   - 대화 시작: "iPhone, Android, Windows PC 중 실제로 손에 있는 기기는 무엇인가? 없는 환경은 README에 '미검증'으로 적거나 빌릴 곳을 D5 전에 정한다."
   - **해소 (2026-11-09)**: Windows PC, Android, MacBook M3(macOS 26 / Chrome 156) 보유. iPhone은 D6에 빌려서 1회 확인한다.
3. **11일 안에 1인이 필수 4영역 + 선택 기능 + 자체 호스팅 운영을 모두 하는 일정은 빡빡하다.** 일정표에 하루 단위 여유가 D11 하나뿐이다.
   - 대화 시작: "선택 기능은 '댓글까지만 해도 성공'으로 미리 정해 두면, D7 이후 결정이 쉬워진다."
